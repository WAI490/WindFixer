# WindFixer (ویندفیکسر)

**نسخه ۱٫۱٫۱** · [English README](README.md)

یک اسکریپت کوچک بچ (Batch) برای ویندوز که دو کلید رجیستری باقی‌مانده از
Windscribe را پاک می‌کند تا برنامه، سیستم را مثل یک نصب تازه ببیند.

> **سلب مسئولیت:** این پروژه **فقط برای اهداف آموزشی** است.
> استفاده از آن ممکن است قوانین استفاده (Terms of Service) واینداسکرایب را
> نقض کند و باعث محدودیت حساب یا دستگاه شود. استفاده با مسئولیت خودتان
> است و نویسنده هیچ مسئولیتی در قبال خسارت، از دست رفتن داده یا مسدود
> شدن حساب ندارد.

## چه کار می‌کند

این دو کلید را از بخش کاربر فعلی (`HKCU`) پاک می‌کند:

| # | کلید رجیستری |
| --- | --- |
| ۱ | `HKCU\Software\Microsoft\Windows\CurrentVersion\NetControlPort` |
| ۲ | `HKCU\Software\Windscribe\Windscribe2` |

قبل از پاک کردن، پروسه‌های Windscribe را به‌طور کامل می‌بندد و بررسی
می‌کند که برنامه واقعاً بسته شده باشد — اگر برنامه هنوز باز باشد،
اسکریپت متوقف می‌شود و هیچ چیزی را پاک نمی‌کند.

## کی به WindFixer نیاز دارید؟

گاهی Windscribe روی یک سیستم گیر می‌کند: وارد حساب نمی‌شود یا مدام آن
سیستم را «قبلاً ثبت‌شده» حساب می‌کند، چون دو کلید باقی‌مانده در
رجیستری می‌مانند (`NetControlPort` و `Windscribe2` زیر HKCU). در این
حالت از حساب Windscribe خارج شوید، `WindFixer.bat` را اجرا کنید و با
**Y** تأیید کنید؛ اسکریپت هر دو کلید را حذف می‌کند (و حذف هر کدام را
جداگانه راستی‌آزمایی می‌کند) تا برنامه دوباره از یک وضعیت تمیز شروع
کند.

## پیش‌نیازها

- ویندوز ۱۰ یا ۱۱
- دسترسی Administrator (اسکریپت خودش با UAC سطح دسترسی را بالا می‌برد)
- Windscribe نصب باشد و قبل از اجرا از حساب **خارج شده باشید (Log Out)**

## روش استفاده

۱. از حساب Windscribe خود خارج شوید.
۲. روی `WindFixer.bat` دوبار کلیک کنید.
۳. پنجره UAC را **با همان کاربر ویندوزی که Windscribe را اجرا می‌کند**
   تأیید کنید (در غیر این صورت `HKCU` به پروفایل کاربر دیگری اشاره
   می‌کند و اتفاقی نمی‌افتد). بعد از بالا رفتن سطح دسترسی، اسکریپت
   نام کاربر و مسیر پروفایل فعلی را نشان می‌دهد — بررسی کنید که مال
   خودتان باشد.
۴. برای تأیید **Y** و برای لغو بدون هیچ تغییری **N** را بزنید.
۵. خلاصه پایانی را بخوانید، بعد Windscribe را باز کنید و وارد شوید یا
   حساب جدید بسازید.

## خواندن نتیجه

برای هر کلید، نتیجه جداگانه و راستی‌آزمایی‌شده چاپ می‌شود — یک کلید
فقط وقتی «پاک شد» گزارش می‌شود که اسکریپت دوباره رجیستری را بخواند و
نبودنش را تأیید کند:

| پیام | معنی |
| --- | --- |
| `[OK] ... deleted` | کلید وجود داشت، پاک شد و نبودنش تأیید شد. |
| `[NOT FOUND] ... already clean` | کلید از قبل نبود. این طبیعی است. |
| `[FAILED] ... could not be deleted` | کلید وجود دارد ولی پاک نشد (قفل است یا دسترسی رد شده). این خطا به‌جای NOT FOUND قایم نمی‌شود، در خلاصه پایانی می‌آید و اسکریپت با کد خروج `1` تمام می‌شود، نه با ادعای موفقیت. |

کدهای خروج: `0` = انجام شد (یا خودتان لغو کردید)، `1` = متوقف شد یا
با خطا تمام شد.

## چه کارهایی نمی‌کند

- به `HKLM` یا تنظیمات کل سیستم دست نمی‌زند.
- **بکاپ نمی‌گیرد** — این عمدی است. اگر بکاپ می‌خواهید، **قبل از اجرا**
  خودتان از کلیدها خروجی بگیرید:

  ```
  reg export "HKCU\Software\Microsoft\Windows\CurrentVersion\NetControlPort" NetControlPort.reg
  reg export "HKCU\Software\Windscribe\Windscribe2" Windscribe2.reg
  ```

## برگرداندن (Restore):

```
reg import NetControlPort.reg
reg import Windscribe2.reg
```

(فقط وقتی کار می‌کند که قبلش خودتان خروجی گرفته باشید — بالا را ببینید.)

## نکته آنتی‌ویروس و SmartScreen

این اسکریپت دسترسی Administrator می‌گیرد، پروسه می‌بندد و کلید
رجیستری پاک می‌کند؛ پس ممکن است بعضی آنتی‌ویروس‌ها یا SmartScreen
ویندوز هشدار بدهند. برای هر ابزاری از این جنس این واکنش طبیعی است.
اسکریپت فقط یک فایل متنی ساده `.bat` است، بدون دانلود و بدون استفاده
از شبکه — قبل از اجرا آن را در Notepad بخوانید و فقط از نسخه همین
مخزن استفاده کنید.

## یادداشت‌ها

- پیام `[NOT FOUND]` طبیعی است — ممکن است کلید از قبل پاک شده باشد.
- روی ویندوز ۱۰ و ۱۱ (نسخه 22H2 به بالا) بررسی شده و با نسخه دسکتاپ
  Windscribe تست شده است.
